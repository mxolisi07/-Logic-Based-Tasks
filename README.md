# Developer Gadgets Project

## Overview
A JavaScript project to analyze developers and their gadgets (phones, laptops, computer setups).

## Features
- Count incomplete setups
- Find most/least trusted phone brands
- Identify developers without gadgets
- Compare who has the most phones, laptops, setups, or monitors
